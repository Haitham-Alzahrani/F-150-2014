### Critical design note — water pump

The 3.7L Cyclone uses an **internal water pump driven by the timing chain**,
located inside the front cover. It is not belt-driven and not externally
accessible.

**Consequence:** when it fails, coolant enters the crankcase rather than
leaking externally. Any coolant loss without a visible external leak means
checking the engine oil for contamination (milky appearance, over-full
level) as the first step. Replacement is a major job requiring front cover
and timing chain removal.

## 8. OBD-II and diagnostics reference

### Connector

| Bus | Pins | Speed | Modules |
|---|---|---|---|
| **HS-CAN** | 6 (H) / 14 (L) | 500 kbps | PCM, ABS, RCM, power steering |
| **MS-CAN** | 3 (H) / 11 (L) | 125 kbps | Body control, instrument cluster, SYNC, doors, HVAC |

Protocol: ISO 15765-4 CAN. **[SPEC]**

Powertrain data is on HS-CAN. A full vehicle scan requires both buses —
adapters without MS-CAN support will silently miss half the modules.

### Standard OBD-II services

| Mode | Returns |
|---|---|
| `01` | Live data PIDs |
| `03` | Stored DTCs |
| `06` | On-board monitor results — **includes per-cylinder misfire counters (MIDs 01–06)** |
| `07` | Pending DTCs |
| `09` | Vehicle information (VIN) |
| `0A` | Permanent DTCs |

Mode 06 misfire data is standardised, not Ford-proprietary — it is readable
without enhanced PID definitions.

### Software

FORScan (Windows) provides Ford-specific enhanced PIDs, all-module scanning,
and service procedures that generic OBD-II tools cannot access. Enhanced
PIDs — actual VCT cam position, EGR valve position, individual injector
data — require it or an equivalent Ford-capable tool.
